### [Our decision on Cursor following its acquisition by SpaceX](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex)
OpenAI is pulling its models out of Cursor now that Cursor has been acquired by SpaceX.
**BREAKING** · 1 min read

OpenAI confirmed it's winding down the contract that supplies models to Cursor, triggered directly by Cursor's acquisition by SpaceX. If your team standardized on Cursor assuming continuous access to OpenAI's models, that assumption just broke — a coding tool's model backend is its own vendor-risk surface, not a fixed detail of the product you procured.

> Our decision to wind down our contract providing OpenAI models to Cursor following its acquisition by SpaceX.

**BREAKING** · 1 min read

Wiz's Red Agent got into Snowflake's internal Jira through a flaw introduced by a GitHub Copilot-assisted pull request — not a novel exploit technique, just an AI-authored fix that shipped without the scrutiny a human-only PR might have gotten. For teams treating autofix suggestions as low-risk because they're 'just a PR like any other,' this is the concrete case for holding that PR to the same review bar as anything hand-written.

> Wiz Red Agent finds its way into Snowflake's internal Jira through a flaw in a GitHub Copilot–Assisted PR.

### [Claude Code permanently raising weekly limits by 25% from September 14](https://twitter.com/ClaudeDevs/status/2093742321473065266)
Claude Code's standard weekly usage limits are going up 25% for good, starting September 14.
**BREAKING** · 1 min read

Anthropic says it's permanently raising standard weekly limits in Claude Code by 25% for Pro, Max, Team, and seat-based Enterprise plans starting September 14, with the current temporary 50% increase holding until then. If your team has been planning capacity against weekly caps, both numbers matter: the temporary bump ends, but the new permanent baseline lands higher than where you started.

> Starting September 14, we're permanently raising standard weekly limits in Claude Code by 25% for Pro, Max, Team, and seat-based Enterprise plans. Until then, the current 50% increase will be in place.
