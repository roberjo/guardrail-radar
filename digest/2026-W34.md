Hands is a Rust MCP/CLI that lets a coding-agent harness (Grok, Codex, Claude Code, OpenCode, etc.) drive a real Chrome profile via actual OS-level input — not Playwright, Puppeteer, or a remote debugging port — specifically so sites that key off CDP/automation flags mostly don't detect it as automated.
