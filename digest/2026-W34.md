`Notable` · 1 min read

Hands is a Rust MCP/CLI that lets a coding-agent harness (Grok, Codex, Claude Code, OpenCode, etc.) drive a real Chrome profile via actual OS-level input — not Playwright, Puppeteer, or a remote debugging port — specifically so sites that key off CDP/automation flags mostly don't detect it as automated. Worth knowing this class of tool exists before assuming your bot-detection or session-monitoring controls would catch an unsanctioned agent using one.

> I built Hands because I wanted a coding agent to use this Windows PC and a real Chrome profile the way I do: look at the screen, move the real mouse, type, click , without turning Chrome into an automation browser. ### [One senior engineer's unfiltered account of what full agent delegation actually feels like.](https://news.ycombinator.com/item?id=49389408)
