  • Our decision on Cursor following its acquisition by SpaceX

    Breaking1 min read

    OpenAI is pulling its models out of Cursor now that Cursor has been acquired by SpaceX.

    OpenAI confirmed it's winding down the contract that supplies models to Cursor, triggered directly by Cursor's acquisition by SpaceX. If your team standardized on Cursor assuming continuous access to OpenAI's models, that assumption just broke — a coding tool's model backend is its own vendor-risk surface, not a fixed detail of the product you procured.

  • AI-Generated GitHub Copilot “Autofix” Allowed Compromise of Snowflake's Jira

    Breaking1 min read

    A red-team exercise found that an AI-generated GitHub Copilot 'Autofix' PR was the actual entry point into Snowflake's internal Jira.

    Wiz's Red Agent got into Snowflake's internal Jira through a flaw introduced by a GitHub Copilot-assisted pull request — not a novel exploit technique, just an AI-authored fix that shipped without the scrutiny a human-only PR might have gotten. For teams treating autofix suggestions as low-risk because they're 'just a PR like any other,' this is the concrete case for holding that PR to the same review bar as anything hand-written.

  • Anthropic appears to be A/B testing reduced effort levels in Claude Code

    Breaking1 min read

    Anthropic is quietly A/B testing lower effort levels for some Claude Code sessions, server-side, with no client update to explain it.

    A Claude Code user's own investigation found Anthropic enrolling Fable 5 sessions on Claude Code 2.1.236+ into a server-side experiment that shrinks the effort scale, while older client versions and Opus 5 are left untouched. It's probably an A/B test, so not every session sees it — but because the mechanism is server-side, nothing in your local install or changelog will tell you if 'high' effort quietly started behaving like 'low' for your account.

  • Claude Code permanently raising weekly limits by 25% from September 14

    Breaking1 min read

    Claude Code's standard weekly usage limits are going up 25% for good, starting September 14.

    Anthropic says it's permanently raising standard weekly limits in Claude Code by 25% for Pro, Max, Team, and seat-based Enterprise plans starting September 14, with the current temporary 50% increase holding until then. If your team has been planning capacity against weekly caps, both numbers matter: the temporary bump ends, but the new permanent baseline lands higher than where you started.

    Read the source excerpt
    Starting September 14, we're permanently raising standard weekly limits in Claude Code by 25% for Pro, Max, Team, and seat-based Enterprise plans. Until then, the current 50% increase will be in place.

  • oMLX

    New Product1 min read

    A Mac LLM inference server that claims to cut Claude Code and Cursor's agent wait times from 90 seconds down to about 5.

    oMLX turns a Mac into a full local LLM inference server — serving text, vision, OCR, embedding, and reranker models with continuous batching and a RAM+SSD tiered KV cache — with OpenAI- and Anthropic-compatible APIs that drop into Claude Code and Cursor directly. For shops where sending code context to a third-party API is the actual blocker, running inference entirely on developer hardware changes the compliance conversation more than a faster response time does.
